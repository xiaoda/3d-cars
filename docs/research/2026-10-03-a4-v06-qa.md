# A4 v0.6 车头专项：依据、改动与验证

日期：2026-10-03。开始前将 v0.5 提交为 `3955029`，保留可回退基线。开发验收时本阶段改动尚未提交、推送；后续提交状态以 Git 历史为准。本阶段未部署。

## 参考边界

主依据仍为冻结的 Audi 04/19 四视尺寸图（本轮实际查看）。官方设计说明区分 basic / advanced / S line 外观及三种前灯版本，S line 的蜂窝、进气口与机盖下狭缝不能任意拼到横条前脸上；选装 LED 有上部一条长光导和五个短分段。[Audi 官方设计说明](https://www.audi.com/en/the-audi-a4-major-upgrade-for-the-bestseller-2019-11884/the-design-11889)

本轮沿用图纸横条格栅、灯组轮廓和侧进气口观察形态，去掉旧版额外下沿发光框。图纸不提供完整配置身份，不能称“已锁定原厂选装组合”；灯腔 85 mm、格栅 105 mm、侧腔 95 mm 及双反射杯均为建模估算。2022 外观照片仅作辅助，未照搬蜂窝格栅。不下载或导入现成车模。

## 实现

- `aperture.ts`：凸多边形棱柱逐三角形差集，真实移除前段车身与封口的孔内面；跨 x=-1.80 m 限制平面的三角形精确裁切。插值 UV 与法线，保持绕序；支持多个孔及镜像轮廓，拒绝非凸/非有限输入。不是通用 CSG，输入限定无分组的 position / normal / uv 静态几何。
- `frontShape.ts`：五个开口、深度和前基面定位共用参数，避免裁孔与装配各用一套轮廓。
- `frontAssembly.ts`：倒角框、凹入内壁、背板、闭合格栅横条及纵撑、号牌安装座、双反射杯、实体透镜、上沿分段光导、透明罩和侧腔圆形单元。罩体不投实心阴影，白模隐藏以露出内部；标准材质 / GLB 恢复可见。
- 机盖前角抬升参数从 0.125 减到 0.072 m；在 x=-2.30 m 的指定肩部取样，高于中心由约 43 mm 减至约 17 mm。这是参数回归，不是实车误差测量。
- 前封口圆角径向范围从 12% 收到 4%，相应缩短 Hermite 末端切线，并把 8 层网格分配给收紧后的圆角。只收窄范围而不缩短切线曾造成投影回折，逆映射测试捕获后修复，没有放宽其容差。
- 前翼子板纵向收角入口由 `t^1.16` 改为有界二阶曲率函数，降低起点曲率尖峰。保留横向四次收角分布；曾比较六次方案，其角部高光更尖，未保留。
- 正向法线检查覆盖左右凹腔、倒角、背板和反射杯，不以 DoubleSide 代替正确绕序。

## 冻结约束

`public/references`、`calibration.ts`、`cabinSurface.ts`、`cabinEvidence.json`、`studio.ts` 与基线无差异；官方尺寸、轴距、车顶纵向控制点不变。没有调曝光、灯光或车漆来夸大形态变化。哈希见 [manifest.json](v06/manifest.json)。

## 自动验证

- `npm test`：9 个测试文件、59 项通过。裁孔测试与凹腔测试均先在缺失 / 旧实现上失败，再实现通过。
- 保留全车包围盒、镜宽、车高、轴距、轮拱、封口共边及法线切线测试；预算仍严格小于 250000 三角面。
- 新增孔外/孔内射线、投影面积、前段限制、双孔和镜像、UV/单位法线、非法轮廓、蒙皮无遮挡与凹腔背板深度、透明罩模式恢复、前缘鼓包和收角入口曲率检查。
- 旧“前灯位于完整蒙皮外”的断言改为更强的真实开口 + 凹腔封闭射线检查；后灯原贴合测试保留。前后灯密集取样每侧超过 30 点。
- 原逐数字构造 expect 的全顶点检查曾超过 Vitest 5 秒限时；改为对每个完整属性数组做 `every(Number.isFinite)`，覆盖范围不减少，没有提高超时或放宽数值容差。
- `npm run build` 通过；主包约 904 kB，保留 >500 kB 告警，未提高告警阈值。

## 视觉观察与剩余差距

灯组不再是完整黑面上的矩形描线，格栅 / 侧腔可看到内壁和背板，机盖前角鼓包减轻。但近景仍能看出外角高光、机盖前缘带状过渡、风挡下方宽漆面及门缝的概括形态；透镜光学结构没有精确复刻。圆形侧灯单元与配置关系仍需核实。轮毂、胎侧、尾部、内饰与真实玻璃层次不在本轮完成范围。没有照片级、毫米级精度或“还原率”承诺。
