研究对象为 2019 年发布的 Audi A4 Sedan B9 中期改款欧洲标准轴距版，不是 A4L、S4、RS4 或 Avant。第一轮以官方尺寸图的外观为主，不宣称准确复刻一个已核定的动力/选装配置。

## 估算与简化

- 车身横截面、曲率、机盖隆起、玻璃曲率和门缝均为二维图纸基础上的程序化估算。
- 轮胎半径、宽度与轮毂尺寸为比例估算，不作为已核实的选装规格。
- 格栅、灯腔、后视镜、轮毂辐条为外观近似，不具有制造精度。
- 金属漆、玻璃、橡胶由物理材质参数近似，并非原厂 BRDF 或测量数据。
- 首版没有真实精细内饰、底盘、门机构，也没有路径追踪、驾驶物理或成片视频。
- 不使用下载的第三方车模、不使用隐藏配置器三维资产、不以 AI 生成参考图代替官方资料。
- 官方素材仅保存在本地供本次参考研究；公开发布或商业用途需另行核对素材及品牌的相关使用条款。

## 验收方式

1. 正交前/侧/后视图检查轮廓，优先检查车长、轴距、轮位和车身高度。
2. 灰色白模下检查曲面连续性，不以强反射或景深掩盖问题。
3. 标注已知差异，不发布未经测量的“还原率”。
4. 多角度可见缺陷记录在 README/后续迭代中。
