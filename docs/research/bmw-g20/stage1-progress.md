# BMW G20 阶段 1：执行记录

用户在阶段 0 建议后明确要求“开始下一阶段开发”。本批按固定样车可见外观推进任务 2–4；不把这次授权解释为已证实原厂选装或尺寸，也不授权跳过车头可行性关。

## 范围决定

- 允许：证据/控制网契约、人工标注、相机初值、共同低自由度骨架、独立本地对比工作台。
- 不允许：宣称精确销售配置已锁定、把基础规格转成照片车测量值、进入精细曲面/整车装饰开发。
- 阶段 0 的 U01/U02 保留未知，缩小对外描述为官图样车可见外观；U03 转为明确标记的尺度假设，必须以跨图残差验证。
- `config-lock.json` 原资料关状态保留；新增受限的 `studyApproval`，与完整资料锁定分开。

## 实施顺序

- [x] 任务 2：单位、置信等级、控制网运行时校验与骨架配置。
- [x] 任务 3：透视/裁剪/标注坐标测试，三张照片标注和相机初值。初值不等于最终相机标定。
- [x] 任务 4 工程部分：独立 BMW 工作台、本地原图选择逻辑、三个骨架机位、参数操作及 A4 回归。
- [ ] 任务 4 视觉关：官方原图在浏览器内叠加、姿态歧义复核与用户签收。工具选择原图时拒绝文件路径访问，未绕过；只验证了骨架画面，不能把本批记为阶段 1 完整验收通过。

结果与具体限制见 [stage1-qa.md](stage1-qa.md)。本批停在阶段 1，不开始任务 5–7 的曲面小样。

本阶段相机残差只说明“假定骨架与照片的重投影一致程度”，不等于真实表面误差。轮廓点与固定三维对应分开；留出照片不参与本批骨架调整。
