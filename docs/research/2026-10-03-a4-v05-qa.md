# A4 v0.5 验证记录

日期：2026-10-03。基线 `124bfa5`，本轮开发未自动提交、推送或部署。

## 实现与证据

- 新 `cabinSurface.ts` 集中管理弧形风挡、闭合密封边界、斜置 B 柱、后三角窗分界和门框投影。
- `cabinEvidence.json` 门框由冻结 PDF 采样；前门路径 951 + 950（跳过前两项翼子板底边），后门路径 1011。风挡俯视路径 1665 / 1667 / 1668 只作为观察记录，风挡三维参数仍为人工估计，并非直接从二维数据解出精确曲面。
- `scripts/extract-cabin-evidence.py` 可选复现上述数据，先验证 PDF SHA-256，需 PyMuPDF，不参与 npm 构建，不修改 PDF。
- `bodyShell.ts` 的前角抬升由带斜率跳变的线性截断变为平滑三次权重。顶面定位函数供机盖/尾厢边界使用。
- 修复车顶/玻璃/镜像侧框朝内的法线；`reverseFaces()` 同时翻转三角形绕序与法线，不仅改材质的 DoubleSide。

## 冻结约束

## 工具限制与计划调整

浏览器工具指定项目路径保存截图/脚本结果时返回 `Access denied ... not within any of the configured workspace roots`。保留限制，不改安全策略，不换通道写入被拒绝的截图路径。继续使用默认截图以及内存中的真实应用 PNG 作视觉检查。因此本轮没有新的仓库内图片对照归档，旧 v0.4 样张未动；二进制导出也仅在内存验证，不将其冒称已保存。

开发中无效旧元素 UID 通过重新获取快照解决；内部引擎批量检查不驱动 React 控件，真实交互另行检查。未新增浏览器扩展、外网服务或运行时依赖。
