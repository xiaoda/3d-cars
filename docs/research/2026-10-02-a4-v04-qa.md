# A4 v0.4 曲面精修验证记录

日期：2026-10-02。范围：肩线、翼子板、前后端衔接及附属饰件定位。当前未提交、未推送、未部署公网。

## 实现

1. `bodyShell.ts` 统一连续横截面、轮拱裁切、侧面取点和前后端 Hermite 圆角。横向控制点是人工估算，不是新获取的官方三维数据。
2. 轮拱只截去横截面下部，上肩采用固定参数网格；在轮拱圆弧和开口边界增加纵向站位。消除初轮迭代中采样错位引起的肩线高光锯齿。
3. 前后端外围预留 55 mm 的估算过渡范围；封口 100 段边界与车身截面逐点匹配，其余 20 段闭合底边。不是在原有硬角上仅平均法线。
4. 车身、封口、尾灯和后下包围可从参数函数数值微分求法线；三角形绕序与法线同步调整。高光可平滑，但尚未验证整车二阶曲率连续，更不是汽车 A 级曲面认证。
5. 端部饰件通过反求 `(z,y)` 对应的蒙皮 `x` 贴合，尾灯外角可落在相邻翼子板上。越界或非有限坐标显式报错，未用任意扩大蒙皮掩盖越界。
6. 后下包围和尾灯增加局部细分。最终 **203516 三角面、301 Mesh**，v0.3 为 172776 三角面，增加约 17.8%；未放宽 250000 三角面预算。
7. `setInspectionPose()` 是内部可复现机位接口；界面操作不变。没有新引入运行时依赖。

## 已知限制 / 开发记录

- 机盖前角仍有不够自然的反射，车尾号牌区、灯腔与底部仍很概括；风挡横向边界和门缝仍不精确。
- 主蒙皮与端面虽对齐，但整车仍包含独立面片、薄玻璃与简化底部，不保证可制造实体或整体水密网格。
- 仅改变现有页面 URL 的 hash，不会主动同步 React 工作区；使用顶部按钮切换或刷新带 hash 的地址。本轮未扩展路由系统。
- 本轮 v0.3 基线保存在忽略目录 `tmp/v04-baseline/src`。尝试归档后删除副本的命令被策略拒绝后没有绕过，完整备份继续保留；测试发现范围已限定到正式源码。
- 当前工作区也包含上轮 v0.3 尚未提交的改动；本次未替用户执行 Git 提交或推送。

结论：完成了本轮曲面衔接和贴合机制改进，仍未达到写实汽车成片质量，不给出全车还原率。
