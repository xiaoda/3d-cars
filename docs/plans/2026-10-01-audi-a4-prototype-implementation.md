# 奥迪 A4 纯代码外观原型实施计划

> 执行说明：按任务逐项实施、验证。本仓库当前没有 Git 元数据，暂不创建工作树或提交。原型不调用现成车模、Blender 或 AI 图生 3D。

**Goal / 目标：** 用官方公开二维尺寸资料约束程序化模型，制作可旋转、可比较、可导出的 A4 外观研究原型。

**Architecture / 架构：** React 负责研究工作台；Three.js 负责独立场景、程序化几何、相机和渲染。官方测量、图像估算与视觉近似在数据和界面中分开标注。

**Tech Stack / 技术栈：** React、TypeScript、Vite、Three.js、Vitest。预览仅监听 127.0.0.1，后台无窗口运行。

## 对象和边界

- 对象：2019 年发布的 Audi A4 Sedan B9 中期改款，欧洲标准轴距，不是 A4L、S4 或 RS4。
- 尺寸基准：官方 04/19 尺寸图，空载车长 4762 mm、车宽 1847 mm、不含天线车高 1428 mm、轴距 2820 mm、前后悬 899/1043 mm、前后轮距 1572/1555 mm。
- 四视图中的轮廓、灯组、轮毂可作为形状参考，但图纸不是制造级 CAD。暂不宣称具体配置完全复刻。
- 首版使用 3D 曲面、真实轮拱缺口、独立车轮、窗面、灯组和格栅，不使用照片平面替代汽车几何。
- 曲面截面、灯腔深度、轮胎半径、轮毂样式及材质均为估算，必须显式标注。
- 不做内饰精模、开门、行驶物理、路径追踪或视频编码。

## 任务 1：冻结资料与参数

文件：`public/references/`、`src/data/a4.ts`、`docs/research/audi-a4-sources.md`。

1. 保留已下载的官方 PDF 和用于查看的渲染图。
2. 记录来源、版本、单位、脚注与不确定性。
3. 用测试约束前悬 + 轴距 + 后悬 = 车长，轴心位置和左右对称。
4. 执行 `npm test`，先观察缺少模块导致失败，再实现参数模块并通过。

## 任务 2：几何内核

文件：`src/engine/geometry.ts`、`src/engine/car.ts`、`src/engine/car.test.ts`。

1. 建立米制坐标：X 纵向（负为车头）、Y 向上、Z 横向。
2. 建立可测试的连续截面采样和轮拱边界函数。
3. 生成车身与座舱曲面，再添加轮胎、轮毂、玻璃、灯组和格栅。
4. 测试尺寸包围盒、前后轴间距、顶点/法线有限性、几何复杂度以及模式切换。

## 任务 3：独立场景和摄影控制

文件：`src/engine/studio.ts`。

1. 建立本地生成的摄影棚环境、阴影与灯光，不额外下载 HDRI。
2. 支持自由轨道相机及前侧、正侧、正前、正后、俯视机位。
3. 支持材质、白模、线框、转向、车灯和自动环绕。
4. 实现独立画面导出和资源释放，初始化失败时展示可读错误。

## 任务 4：研究工作台

文件：`src/App.tsx`、`src/style.css`、`src/main.tsx`。

1. 采用浅色、克制的工业设计工作台，主体留给车模。
2. 左侧提供模型控制和尺寸；底部提供固定机位；参考面板展示官方图纸与来源。
3. 持续展示“研究原型 / 估算曲面”提示，不展示虚构的相似度评分。
4. 提供键盘可访问控件、窄屏布局和加载/失败状态。

## 任务 5：验证和交付

1. `npm test` 全部通过。
2. `npm run build` 完成 TypeScript 检查和生产构建。
3. 隐藏启动本任务预览进程，写日志并记录 PID、目录和端口。
4. Chrome DevTools MCP：先 list_pages，再创建唯一 isolatedContext；所有操作指定本任务 pageId。
5. 检查页面快照、实际截图、控制台、机位切换、模式切换、转向及导出。
6. 至少检查前侧、正侧、正前、后侧；视觉发现的问题回到几何修正。
7. 保存 README，说明原型局限、来源与启动方法。性能仅报告实际环境，不将无头浏览器性能冒充 RTX 3060 的实测。
